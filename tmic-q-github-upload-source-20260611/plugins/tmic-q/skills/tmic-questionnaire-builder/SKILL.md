# TMIC Questionnaire Builder

默认用中文回应。这个 skill 复刻 GPT「TMIC 问卷助手」中“生成问卷表格文件”的工作流，用于从概念卡生成 TMIC 概念测试问卷、交付可手动导入 TMIC 的完整问卷工作簿和上传专用单表；也用于处理用户修改后的完整问卷，按修改版最终内容重算题号、调整逻辑，并重新输出完整工作簿和上传专用单表。默认流程在交付表格文件后结束，不接管 Chrome，不进入 TMIC 网站编辑分页或设置网页逻辑。

## Hard Rules

- 不得只输出修改部分、概念段、摘要、逻辑说明或示例；最终交付必须是完整整卷。
- 概念卡生成模式下，没有本次概念卡时，只输出：`请提供本次概念测试的概念卡。`
- 修改版问卷处理模式下，不要求概念卡；只要用户上传修改后的完整问卷，就以该文件作为最终问卷主体处理。
- 概念卡生成模式下，先提取信息点并请用户确认；用户确认后直接生成完整 `.xlsx`，不再二次确认。
- 生成完整 `.xlsx` 后，必须交付完整工作簿和上传专用单表，并明确说明流程已结束；不得要求用户继续提供 TMIC 网址、编辑页链接或 Chrome 授权。
- 默认流程不得接管 Chrome、不得进入 TMIC 网站、不得自动新建问卷、上传文件、分页、设置网页逻辑、保存或发布问卷。
- 如果用户只提供 TMIC 网址或编辑页链接，说明本 skill 当前流程到表格文件交付为止；需要概念卡或修改版问卷时，继续回到概念卡/信息点/表格生成或问卷审核流程。
- 当概念卡已提供、信息点已确认、TMIC 模板和《问卷格式.xlsx》均可读取时，必须实际生成 `.xlsx` 文件。
- 若必要文件或环境缺失，必须说明具体阻塞；可以输出可复制的完整表格内容，但不得虚称已验证可导入或已完整复刻。
- 模板题号、题目编号、内部标签和源表编号只能用于代码定位，绝不能出现在用户可见内容中。
- 唯一例外：整卷答题逻辑和整卷甄别逻辑必须使用最终输出问卷表格中的题目顺序号，例如 `Q1.请问你的性别`。
- 题文、选项、概念信息点不得优化、润色、纠错、归纳、分类、改写或补写。
- `完整TMIC问卷导入表格` 和上传专用单表中不得包含页面占位文字，例如 `分页`、`分页：第2页`、`第2页`。
- 完整工作簿中的 `完整TMIC问卷导入表格` 必须包含三列：`题号`、`问卷导入内容`、`逻辑`；题目行标示最终题号，例如 `Q24`，选项行题号列留空。
- `逻辑` 列参考模板逻辑标示方式展示题目级、选项级、显示、终止、随机、互斥等逻辑，并统一使用灰色字体。
- `逻辑` 列中涉及题目引用时必须使用最终题号，例如 `Q24.题目原文`；不得暴露模板内部编号。上传专用单表必须仍为单列，不得包含 `题号` 或 `逻辑` 列。
- 用户上传修改后的完整问卷时，必须按修改版最终题目顺序重算 `Q1`、`Q2` 等题号；逻辑列中的旧题号引用必须同步更新为新题号。
- 修改版中被删除的题目或选项不得继续出现在完整工作簿、上传专用单表、整卷答题逻辑或整卷甄别逻辑中；如逻辑仍引用已删除内容，必须在 `逻辑校验结果` 标为重大问题。
- 修改版新增题、新增选项、改写题文或改写选项时，不得发明新的业务逻辑；只有原逻辑列能推导的规则才可保留/重算，其余在 `逻辑校验结果` 标为一般问题或重大问题。
- 完整工作簿必须新增独立标签页 `分页指导`，专门用简明方式标示分页范围，例如 `第一页：Q1-Q11`、`第二页：Q12-Q14`；不得把分页标示插入问卷正文或上传专用单表。
- `逻辑校验结果` 必须列出整卷所有可能影响逻辑设置、甄别、随机、互斥、导入后人工配置的问题和意见；重大问题用红字，一般问题用橙字，无问题用黑字。
- 模板占位信息必须在 `逻辑校验结果` 中提示，例如题文中的 `XX`、选项中的 `品牌1`、`品牌2`、`品牌3`、`……`，以及未明确具体品牌/选项的筛选终止条件。

## Work Modes

### 1. 概念卡生成表格模式

触发：用户提供概念卡并要求生成 TMIC 概念测试问卷。

流程：

1. 确认存在概念卡；没有则只输出固定提示。
2. 从概念卡提取“未统一层级信息”，并请用户确认。
3. 用户确认后，读取 TMIC 模板问卷和《问卷格式.xlsx》。
4. 用已确认信息点替换三道目标选择题的概念选项，并追加固定互斥选项。
5. 对不相信/可信度相关选择题，为每个信息点立即追加一道多行文本追问题。
6. 生成完整整卷导入表、逻辑校验结果、整卷答题逻辑、整卷甄别逻辑。
7. 在完整工作簿的 `完整TMIC问卷导入表格` 中新增 `题号` 和 `逻辑` 列，题目行逐条标示 `Q1`、`Q2` 等最终题号，并逐行标示题目/选项相关逻辑；上传专用单表仍保持单列。
8. 在完整工作簿中新增 `分页指导` 标签页，按模板 `必答题` 分组输出 `第一页：Qx-Qy` 形式的页范围。
9. 自检通过后交付或保存 `.xlsx`，同时提供完整工作簿和上传专用单表。
10. 最终回复只说明已生成哪些表格文件、可手动导入 TMIC，并明确：`本流程到表格文件交付为止。`

脚本建议：

```bash
python scripts/generate_tmic_questionnaire.py \
  --points 已确认信息点.json \
  --output 完整问卷.xlsx \
  --upload-output 上传专用表格.xlsx
```

续接规则：

- 如果上一轮已生成 `.xlsx`，用户只发 TMIC 编辑页链接或网址时，不继续接管网页；回复说明当前 skill 已在表格交付处结束。
- 如果用户在同一请求中同时提供概念卡和 TMIC 链接，仍必须先提取信息点让用户确认；确认后只生成并交付表格文件，不接管 Chrome。
- 如果用户明确要求网页分页、网页逻辑设置、发布或保存 TMIC 后台问卷，说明该操作已不属于当前 skill 默认流程。

### 2. 修改版问卷处理模式

触发：用户上传已修改的完整问卷，并要求“根据修改内容调整逻辑”“重新输出上传专用表格”“审核修改版问卷”“修正逻辑后重新生成文件”等。

流程：

1. 不要求概念卡，不重新提取信息点。
2. 以用户上传的修改版完整问卷作为最终问卷主体；优先读取 `完整TMIC问卷导入表格`，其中 `问卷导入内容` 为问卷正文，`逻辑` 为可重算的逻辑来源。
3. 如用户同时提供上一版完整问卷，识别新增、删除、移动；如未提供上一版，只基于修改版当前内容校验逻辑引用，并在 `逻辑校验结果` 说明限制。
4. 按修改版最终题目顺序重算 `Q1`、`Q2` 等题号。
5. 将 `逻辑` 列中能识别的旧题号引用同步更新为新题号；保留用户已有逻辑文字，不润色、不改写业务含义。
6. 删除修改版中已经不存在的题目、选项和对应上传内容；若逻辑仍引用不存在的题目或选项，在 `逻辑校验结果` 中以重大问题标出。
7. 对新增题、新增选项、改写题文、改写选项：能从现有逻辑列推导的则重算；无法判断是否需要逻辑时标为一般问题或重大问题，不得编造逻辑。
8. 重新输出完整工作簿，包含 `完整TMIC问卷导入表格`、`逻辑校验结果`、`整卷答题逻辑`、`整卷甄别逻辑`、`分页指导`，可另含 `变更识别`。
9. 同步输出上传专用单表，只保留 `问卷导入内容`，不得包含 `题号`、`逻辑`、分页标记、校验说明或操作说明。
10. 最终回复只说明已生成哪些表格文件、可手动导入 TMIC，并明确：`本流程到表格文件交付为止。`

脚本建议：

```bash
python scripts/process_modified_questionnaire.py \
  --input 修改后的完整问卷.xlsx \
  --output-complete 调整后完整问卷.xlsx \
  --output-upload 上传专用表格.xlsx
```

如有上一版完整问卷用于识别变化，可追加：

```bash
  --base-workbook 上一版完整问卷.xlsx
```

## Concept Card Information Extraction

结果必须是“未统一层级信息”：概念卡中的功能标题、模块标题、对应说明句或项目符号都作为同级、独立、平铺的信息点。

提取规则：

- 每个可见标题、说明句或项目符号都是独立信息点。
- 按视觉顺序保留原文。
- 项目符号本身可去除，文字必须保留。
- 不得把标题和说明配对成层级。
- 不得按模块合并。
- 不得归纳、分类、打分、重排、改写或补写。
- 只提取产品功能/内容区可见的功能标题、模块标题、对应说明句或项目符号。
- 排除产品标题、名称、页眉、整体引言、场景铺垫、背景、消费者需求、产品前提等位于具体功能内容块之外的文字。
- 确认信息点时，用阿拉伯数字逐条编号的平铺列表。
- 胎心仪概念卡只可作为层级处理示例；除非当前概念卡实际出现相同文字，不得复用其中内容。

胎心仪示例的正确层级形态：

```text
1. 手持超声检测胎心
2. 手持探头，超声多普勒接触式检测
3. 胎心音监听
4. 可直接听到胎儿心跳，增强感知
5. 实时显示胎心数值
6. 通过对检测信号进行计算并实时提供胎心数据
```

## Concept Replacement And Follow-ups

概念卡生成模式下，在三道指定目标选择题中：

- 用已确认信息点逐条替换概念选项。
- 每个信息点对应一个选项。
- 追加模板要求的固定互斥选项。
- 替换选项数量必须与确认信息点数量一致。

对指定的不相信/可信度相关选择题：

- 为每个信息点立即追加一道多行文本追问题。
- 追问题题干固定为：`请问您不相信“XXX”词句的原因是？`
- `XXX` 必须为信息点原文。
- 追问题数量必须与确认信息点数量一致。
- 每道追问题只在对应信息点被选中时显示。
- 新增追问题必须紧跟控制题之后。

## Output Contract

生成的完整 TMIC 问卷工作簿必须包含五个独立部分，分表或分区呈现，不得混在同一张表里：

1. 完整 TMIC 问卷导入表格
2. 逻辑校验结果
3. 整卷答题逻辑
4. 整卷甄别逻辑
5. 分页指导

如果未读取到某类逻辑，对应部分写：`未从表格中读取到对应逻辑。`

最终报告不需要在对话中重复展开四个表格部分，但必须提供已生成的工作簿/上传专用单表路径，并说明流程已在表格交付处结束。

## Logic Validation

输出两类逻辑前必须先做逻辑校验。至少检查：

- 同一条件是否同时触发显示和问卷结束。
- 答题逻辑源题、选项、目标题是否存在于最终问卷。
- 甄别逻辑源题和选项是否存在于最终问卷。
- 被显示题是否位于控制题之后。
- 新增追问题数量和显示逻辑数量是否与信息点数量一致。
- 是否出现模板编号、内部 ID 或源表编号。
- 是否有本应属于甄别逻辑的规则被放入答题逻辑。
- 修改版问卷中删除题目/选项后是否仍被逻辑引用。
- 题文或选项修改后逻辑文案是否同步。
- 题目顺序变动后逻辑序号是否重算。
- 新增题/新增选项是否缺少必要逻辑或应标注人工确认。
- 题文或选项是否仍包含模板占位，例如 `XX`、`XXX`、`品牌1`、`品牌2`、`品牌3`、`……`。
- 模板中是否存在需按项目确认但无法自动生成明确逻辑的说明，例如目标品牌未给出、收入筛选阈值未明确、基于项目需求做甄别、选项随机、互斥设置等。

校验结果必须逐条列出检查项和意见，并按以下颜色分级：

- `重大问题`：会导致问卷无法完整生成、逻辑断裂、信息点/追问题数量不一致、源题/选项/目标题不存在等，用红字。
- `一般问题`：需要人工确认、上线前替换或导入后配置，但不阻断表格生成，例如品牌占位、`XX` 占位、未明确具体品牌的筛选终止条件、收入/项目需求筛选提醒、选项随机、互斥设置，用橙字。
- `无问题`：已通过的关键检查，用黑字。

若模板写有终止/筛选逻辑但没有明确具体选项或条件，不得生成 `对应选项或条件` 这类假逻辑；必须在 `逻辑校验结果` 中以一般问题提示人工补充。

特殊归属：题目 `您家里有多少位小孩？（包括已出生和怀孕中的孩子数量）` 不得设置为整卷答题逻辑；如存在剔除、终止或不符合条件规则，必须归入整卷甄别逻辑。

## Logic Output Format

整卷答题逻辑按句子输出：

```text
如果「题目序号.题目原文」选择「选项或条件」则显示「目标题目序号.目标题目原文」，否则不显示。
```

新增追问题显示逻辑按句子输出：

```text
如果「题目序号.控制题原文」选择「XXX」则显示「题目序号.请问您不相信“XXX”词句的原因是？」，否则不显示。
```

整卷甄别逻辑按句子输出：

```text
如果「题目序号.题目原文」选择「选项或条件」则问卷结束，否则继续。
```

题目序号来自最终输出 TMIC 问卷表格的题目行顺序；题目、选项、目标题均用最终输出原文。

## Final Self-check

交付前逐项确认：

- 已实际参考必要模板/格式文件或用户上传的修改版问卷。
- 输出是完整整卷导入表。
- 完整工作簿中的导入表包含 `题号`、`问卷导入内容`、`逻辑` 三列；上传专用单表符合 TMIC 单列导入布局。
- 应保留题目全部保留。
- 指定替换和追问题插入已完成。
- 已根据增删改移动同步两类整卷逻辑。
- 已输出逻辑校验结果和两类逻辑。
- 完整工作簿的导入表已新增 `题号` 和 `逻辑` 列，逻辑列为灰色字体，且逻辑引用使用最终题号。
- 逻辑校验结果已按红/橙/黑分级列出重大问题、一般问题和无问题检查项。
- 已输出独立 `分页指导` 标签页，格式为 `第一页：Qx-Qy`。
- 问题定位使用最终顺序号、最终题目原文和相关选项/目标题。
- 注意项和错误项已红色标注。
- 未暴露模板编号、内部 ID 或源表编号。
- 问卷正文导入表和上传专用单表不含分页占位文字。
- 可作为 TMIC 导入用表格。
- 未要求用户继续提供 TMIC 网址、编辑页链接或 Chrome 授权。

任一项失败，不得作为最终结果。
